id: spotify-wrapped
title: Spotify Wrapped
description: Built a <b>Spotify Wrapped-style web app</b> using <b>Flask</b>, <b>Spotipy</b>, and the <b>Spotify Web API</b>. Implemented secure <b>OAuth 2.0 authentication</b> to access user listening history, including <b>top tracks, artists, and genres</b>. Parsed Spotify's JSON responses and aggregated metadata using Python, then rendered the results through <b>interactive Chart.js visualizations</b>. Styled the frontend with <b>Tailwind CSS</b> for a clean, responsive UI and structured it with <b>HTML</b> and <b>JavaScript</b>. Deployed the application to a custom Linux server running <b>NGINX</b> as a reverse proxy, with HTTPS enabled via <b>Let's Encrypt</b>. This project demonstrates full-stack development with third-party APIs, <b>data-driven storytelling</b>, and <b>secure deployment</b> practices using open-source tools and modern web frameworks.
link: https://example.com
methods: 
- Used Spotify Web API with user authentication
- Parsed top tracks, artists, genres
- Visualized data using Chart.js and Tailwind
- Deployed to custom server with NGINX and HTTPS
tech: Flask, Spotipy, Chart.js, Tailwind, Python
